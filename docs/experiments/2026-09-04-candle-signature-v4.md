## 4. แผน V4 ที่ตรึง — เปลี่ยนจาก V3 สามอย่าง ตามที่ ญ.7 ตรึงไว้ก่อนเห็นผล V3

### 4.1 สมมติฐานหลัก — **ทดสอบ interaction โดยตรง**

> *“ผลของ signature ต่อหางฝั่งเสีย ใน `range` regime มากกว่าใน `directional` regime”*

V3 วัดแต่ละ regime แยกแล้วเทียบด้วยตา ⇒ “range ดีกว่า” จึงเป็น **ข้อสังเกต ไม่ใช่การทดสอบ**
V4 ทำให้การเทียบนั้นเองเป็นตัวที่ถือ p-value:

```
DiD = [p90(MAE | cond, range)       − p90(MAE | matched, range)]
    − [p90(MAE | cond, directional) − p90(MAE | matched, directional)]
```

ทิศที่ V3 ทำนาย: **DiD < 0**. **DiD ≥ 0 = ไม่ผ่าน** ไม่ว่าแต่ละ regime เดี่ยว ๆ จะสวยแค่ไหน

### 4.2 estimand — **MAE p90 ไม่ใช่ mean R**

V3 พบว่า effect อยู่ที่หางฝั่งเสียล้วน: `short×range×h10` ตัด MAE p90 จาก 3.451R → 1.930R
ขณะที่ MFE p90 ขยับแค่ 3.451 → 3.471. การวัดที่ mean คือการใช้กำลังทางสถิติไปวัดส่วนที่ไม่ขยับ

### 4.3 การจับคู่ — เปลี่ยนวิธี เพราะ quantile ลบ stratum mean ไม่ได้

V3 ลบ **ค่าเฉลี่ยของ stratum ตัวเอง** ออกจากแต่ละไม้ ซึ่งใช้กับ mean ได้ แต่ใช้กับ quantile ไม่ได้ —
stratum ที่มี 4 แถวไม่มี “p90 ของ stratum” ให้ลบ. V4 จึงสร้างแขนเทียบที่มี **องค์ประกอบ stratum
เหมือนแขน candidate เป๊ะ** (แต่ละ candidate จับคู่ 1 ตัวจาก stratum ของตัวเอง: instrument × session ×
volatility tercile × regime × ทิศ × horizon) แล้วค่อยหา p90 ของทั้งแขน. ไม้ที่ stratum ไม่มีคู่เลย
**ต้องรายงานแยก ห้ามทิ้งเงียบ** (V3 มี 2 จาก 347)

### 4.4 ความไม่แน่นอน · α

- **block bootstrap by (instrument × session)** — หน่วย resampling ที่ protocol §4 ระบุ,
  2000 replicates. **ห้าม resample ราย row**: บาร์ในวันเดียวกันไม่เป็นอิสระต่อกัน CI จะแคบเกินจริงหลายเท่า
- p-value = invert CI: `p = 2 × min(P(DiD* ≤ 0), P(DiD* ≥ 0))`
- **α = 0.0031** — รับมาจากงบ 16 การทดสอบของ V3. V4 ประกาศ primary 8 ตัว ซึ่ง Bonferroni ของมันเอง
  คือ 0.00625 ⇒ การคง 0.0031 ไว้คือการถือเกณฑ์ที่ **เข้มกว่า** ทั้งสองแบบ **เป็นการรับมา ไม่ใช่ต่อรองใหม่**
- **secondary (รายงานเสมอ ตัดสินไม่ได้):** MFE p90 DiD (เช็กกลไก — ถ้า MFE ขยับพอ ๆ กับ MAE
  แปลว่า signature แค่เลือกแท่งใหญ่ ไม่ได้ตัดการย้อน) · mean R DiD (ต่อแกนเดียวกับ V3)

**แต่ยังต้องแก้ เพราะมันเป็นกับดักที่ยังเปิดอยู่:** ครั้งนี้แถวปนเปื้อนบังเอิญตกอยู่ *ก่อน* feed เริ่ม
ถ้าครั้งหน้ามันตกอยู่ *กลาง* หน้าต่าง มันจะดัน `med_range`/`med_vol`/`hi50`/`lo50` ของ 50 แท่งถัดไป
จนเงื่อนไข `rng > 1.5 × med_range` เป็นเท็จเกือบทั้งหมด **โดยไม่มี error ให้เห็น**

**ที่ทำไปแล้ว:** query ของ V4 ตัดที่ `opened_at >= 2026-08-28` ทั้ง Gate 0 และตัววัดผล
**ที่ยังไม่ทำ (เสนอ ยังไม่ลงมือ — แตะ ingest = L3 ต้องมี owner approval):**
1. ให้ indicator ส่ง timeframe จาก period ของ chart จริงแทนช่องกรอกอิสระ
2. ให้ `ingest` ปฏิเสธ payload ที่ระยะห่างระหว่างบาร์ไม่ตรงกับ timeframe ที่อ้าง
3. ลบหรือ re-label 255 แถวนั้น — **เขียน/ลบข้อมูล = ต้องมี migration + Gate 0 + independent review**

## 7. เกณฑ์ตัดสิน V4 — รับมาจาก ญ.8 ไม่แก้

| ระดับ | เงื่อนไข |
|---|---|
| **FAIL** | interaction ไม่มีนัยสำคัญ **และ** ไม่มี distributional difference ที่ MAE p90 |
| **INCONCLUSIVE** | มี effect ทิศเดียวกับ V3 (DiD < 0) แต่ไม่ผ่าน p < 0.0031 ที่ n ≥ 285/ช่อง |
| **PROMISING** | effect สม่ำเสมอและทิศเดียวกันข้าม **instrument และ session** (ไม่ใช่แค่ pooled) — จุดที่ **เริ่มพิจารณาสร้าง Signal Observation Engine** ได้ (ญ.9) |
